# 了了了试卷 · 了了了Test

> 探索未至之境 · 自己的刷题小助手

---

## 这是什么？

**了了了试卷** 是了了了岭工作室旗下的 **个人刷题工具**。

收集整理各类试卷，打开网页就能刷——客观题自动判分出结果，主观题给标准答案自己核对，全程不用登录，刷题记录存在自己浏览器里，隐私又方便。

---

## 规划方向

- ✅ **客观题自动判分** — 选择/判断/填空自动打分，做完立刻出结果
- 📝 **主观题参考答案** — 大题/简答题提供标准答案，自行核对
- 📚 **试卷分类归档** — 按科目/年级/年份整理，找卷子不费劲
- 💾 **本地存储记录** — 刷题进度存在自己浏览器，不泄露隐私
- 📱 **全端适配** — 手机刷题、电脑看卷都流畅

> ⚠️ 产品仍在规划中，具体功能以上线版本为准。

---

## 技术栈

- 前端：纯 HTML + CSS + JavaScript（零框架）
- 存储：localStorage（浏览器本地存储，无后端）
- 部署：GitHub Pages + Cloudflare 加速
